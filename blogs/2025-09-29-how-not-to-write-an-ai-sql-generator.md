A man’s artificial assistant fails The scenario : You have an enormous and complex database that can be used to support a wide and unpredictable set of use cases. You have some workflows and visualizations built on top of the database, but your data scientists and customers frequently have questions that you haven’t written code to handle. Wouldn’t it be nice if users could just type a question into a box, and the application could dynamically generate a SQL query behind the scenes to retrieve the relevant data?
